# Tech Interview Questions by Company

Interview and online-assessment questions that candidates reported, one folder per company, each with the date it was last reported.

<!-- gen:snapshot:start -->
Snapshot as of 2026-11-19: 5,873 questions, 133 companies.
<!-- gen:snapshot:end -->

Maintained by [TrueInterview](https://trueinterview.io), where every question can be practised.

## How to use

Open a company folder under [`companies/`](companies), or clone the repository and sort the CSV files yourself. Every folder has the same five files:

- `thirty-days.csv`: questions last reported in the past 30 days
- `three-months.csv`: questions last reported in the past 90 days
- `six-months.csv`: questions last reported in the past 180 days
- `all.csv`: every question reported at the company
- `README.md`: the full list as a table, most recently reported first

A question with no reported date is in `all.csv` only. A window with nothing in it is a header-only file. The whole bank as one file is [`data/questions.csv`](data/questions.csv).

## Columns

- **Title**: the question's name
- **Format**: Algorithm, SQL, System Design, and so on
- **Difficulty**: Easy, Medium or Hard, where known
- **Round**: where it was asked (online assessment, phone screen, onsite, take-home), where known
- **Companies Reporting**: how many companies the question has been reported at
- **Last Reported**: `YYYY-MM-DD`, or `YYYY-MM` when only the month is known
- **Link**: the question's page
